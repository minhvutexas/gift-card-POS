# UX Profile

Generated by `setup-ui-ux-skills`. All UI/UX skills in this project read this file before changing layout, copy, or interaction.

## Aesthetic reference

- **Standard:** Stripe
- **Notes:** Neutral zinc surfaces, one teal accent (`brand-*` in `web/tailwind.config.js`) for active state, links and focus. Primary actions are solid ink (black; white in dark mode). Redeem stays green (`success`) so the two main POS actions are told apart. Hairline 1px borders over shadows; 8px radius on controls, 12px on panels. Light and dark themes.

## Banned anti-aesthetics

- Glassmorphism / `backdrop-filter` blur without a high-contrast boundary
- Floating pastel pill badges for ordinary metadata (status pills and interactive filter chips are fine)
- Arbitrary decorative gradients and neon glowing borders
- Multi-color / rainbow gradients on CTAs
- Cartoon empty-state illustrations (people waving / high-fiving)
- Nested scrollbars and decorative icons inside inputs (search, clear, password toggle are allowed)
- Emoji as UI icons or logos

## Accessibility target

- **Level:** WCAG 2.1 AA
- **Contrast:** ≥ 4.5:1 normal text, ≥ 3:1 large text and UI borders, in both themes
- **Touch / focus:** ≥ 44×44px targets (POS keypads larger); visible focus ring (teal) on every interactive element

## Brand tone and microcopy voice

- **Voice:** Utilitarian & Minimal
- **Capitalization:** Sentence case for UI copy and buttons
- **Notes:** Few words, verb-first buttons ("Sell card", "Redeem", "Create salon account"). No hype. Errors say what happened and how to fix it. Customer-facing marketing is bilingual: Vietnamese and English, matching the visitor's language.

## Icon library

- **Library:** Lucide
- **Package / path:** `lucide-react` (web/package.json)
- **Notes:** Product mark is `web/src/components/Logo.tsx` (Lucide Gift on a solid square).

## Agent rules

1. Read this profile before creating or editing any UI, CSS, or microcopy.
2. Prefer skills by task: new page → `page-patterns` (name the pattern before markup); layout / chrome → `viewports`; forms → `forms`; overlays → `surfaces`; loaders → `loaders`; empty views → `empty-states`; motion → `motion`. Before finishing UI, run `ux-audit`.
3. Use only the recorded icon library (or project SVG path). Do not mix icon sets or use emoji as UI icons.
4. Never introduce items on the banned list.
5. Destructive actions always use an explicit confirmation dialog.
